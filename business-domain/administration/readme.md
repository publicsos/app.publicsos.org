# Legal

Welcome to the legal department of the [Public Sos Organization](https://publicsos.org/).

Each department has its own [Code of Conduct](https://publicsos.org/code-of-conduct/).

Each administrative decision is recorded in the format of a file with the following structure:
```
<Department name>
<Date>
<Decision>
<Outcome>
<Status>
<Type>

```
Department: Technical Engineering
Date: 18-02-2025
Decision: Motion for Implementing Board Structure and Decision-Making Procedures
Outcome: Board Structure and Decision-Making Procedures
Status: Final
Type: Motion
```
