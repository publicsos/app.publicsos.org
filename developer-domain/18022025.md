# High-Level Architecture

## Build a large-scale incident response system with geo-spatial data that has a strong focus on data processing, analytics, and security.


### Python (Data Processing Server)
- Handles geospatial data ingestion, processing, and analytics.
- Uses GDAL/OGR, GeoPandas, and PostGIS for geospatial computations.
- Runs background jobs with Celery & RabbitMQ.


### PHP Laravel (Management & Display Server)
- Uses Laravel for the admin panel and API.
- Connects to the Python API for fetching processed data.
- Integrates with a PostgreSQL/PostGIS database for spatial data storage. -- Maybe MONGODB AS WELL

use Spatie\EventSourcing\AggregateRoots\AggregateRoot;

class IncidentAggregate extends AggregateRoot
{
    public function reportIncident(string $id, string $description, string $location)
    {
        $this->recordThat(new IncidentReported($id, $description, $location));
        return $this;
    }

    public function updateIncident(string $id, string $status)
    {
        $this->recordThat(new IncidentUpdated($id, $status));
        return $this;
    }

    public function resolveIncident(string $id)
    {
        $this->recordThat(new IncidentResolved($id));
        return $this;
    }
}

# 1. Command Event Stream
This stream manages roles, responsibilities, and task assignments within the Incident Command System (ICS).

**Bounded Context: Command**
- CommandAssigned → Assigns a role (e.g., Incident Commander, Operations Chief)
- CommandUpdated → Updates the role or responsibilities
- CommandRevoked → Revokes a role from a person

## Command Events

```php
class CommandAssigned
{
    public function __construct(
        public string $commandId,
        public string $personId,
        public string $role,
        public string $incidentId
    ) {}
}

class CommandUpdated
{
    public function __construct(
        public string $commandId,
        public string $role
    ) {}
}

class CommandRevoked
{
    public function __construct(
        public string $commandId
    ) {}
}
```

## Command Aggregate

```php
use Spatie\EventSourcing\AggregateRoots\AggregateRoot;

class CommandAggregate extends AggregateRoot
{
    public function assignCommand(string $commandId, string $personId, string $role, string $incidentId)
    {
        $this->recordThat(new CommandAssigned($commandId, $personId, $role, $incidentId));
        return $this;
    }

    public function updateCommand(string $commandId, string $role)
    {
        $this->recordThat(new CommandUpdated($commandId, $role));
        return $this;
    }

    public function revokeCommand(string $commandId)
    {
        $this->recordThat(new CommandRevoked($commandId));
        return $this;
    }
}
```

## Command Projector (Read Model)

```php
use Spatie\EventSourcing\EventHandlers\Projectors\Projector;
use App\Models\CommandRole;

class CommandProjector extends Projector
{
    public function onCommandAssigned(CommandAssigned $event)
    {
        CommandRole::create([
            'id' => $event->commandId,
            'person_id' => $event->personId,
            'role' => $event->role,
            'incident_id' => $event->incidentId,
        ]);
    }

    public function onCommandUpdated(CommandUpdated $event)
    {
        CommandRole::where('id', $event->commandId)
            ->update(['role' => $event->role]);
    }

    public function onCommandRevoked(CommandRevoked $event)
    {
        CommandRole::where('id', $event->commandId)->delete();
    }
}
```

# 2. Resource Coordination Event Stream
This stream manages personnel, vehicles, and equipment.

**Bounded Context: Resource**
- ResourceAllocated → Allocates resources to an incident
- ResourceUpdated → Updates resource details
- ResourceReleased → Releases resources after use

## Resource Events

```php
class ResourceAllocated
{
    public function __construct(
        public string $resourceId,
        public string $type,
        public string $quantity,
        public string $incidentId
    ) {}
}

class ResourceUpdated
{
    public function __construct(
        public string $resourceId,
        public string $quantity
    ) {}
}

class ResourceReleased
{
    public function __construct(
        public string $resourceId
    ) {}
}
```

## Resource Aggregate

```php
use Spatie\EventSourcing\AggregateRoots\AggregateRoot;

class ResourceAggregate extends AggregateRoot
{
    public function allocateResource(string $resourceId, string $type, string $quantity, string $incidentId)
    {
        $this->recordThat(new ResourceAllocated($resourceId, $type, $quantity, $incidentId));
        return $this;
    }

    public function updateResource(string $resourceId, string $quantity)
    {
        $this->recordThat(new ResourceUpdated($resourceId, $quantity));
        return $this;
    }

    public function releaseResource(string $resourceId)
    {
        $this->recordThat(new ResourceReleased($resourceId));
        return $this;
    }
}
```

## Resource Projector (Read Model)

```php

    }
}
```
