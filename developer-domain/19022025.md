## Core Roles
All these guys needs to be created in the system and seeded with the correct roles.
We need to create a way to sync the latest data so we can keep an eye on the system.
To keep track of the latest data we will used a mixed of techniques.
Monitorul Oficial Data, and a mix of the tools our CTO created to monitor open data.




| Role Name             | Description                                                                                                                                                                                                                                                                                            |
|----------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Incident Commander    | Has full control over the system, can manage all users and settings.                                                                                                                                                                                                                                      |
| Operations Chief      | Manages rescue operations, assigns teams, and monitors field response.                                                                                                                                                                                                                                      |
| Medical Chief         | Oversees medical response, assigns paramedics, and manages field hospitals.                                                                                                                                                                                                                                |
| Fire & HAZMAT Chief | Controls firefighting and hazardous materials response teams.                                                                                                                                                                                                                                           |
| Engineering Chief     | Manages structural assessments and infrastructure repair teams.                                                                                                                                                                                                                                         |
| Law Enforcement Chief | Handles security, police, and military coordination.                                                                                                                                                                                                                                                     |
| Logistics Coordinator | Manages emergency supplies, fuel, and transportation.                                                                                                                                                                                                                                                    |
| Communication Officer | Controls emergency broadcasts, GIS, and public updates.                                                                                                                                                                                                                                                 |
| Shelter Coordinator   | Manages evacuation centers, food distribution, and survivor care.                                                                                                                                                                                                                                         |
| Field Responder       | Has limited access to update reports, mark areas as cleared, and report new incidents.                                                                                                                                                                                                                      |
